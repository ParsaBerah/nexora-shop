# NEXORA Shop

A modern e-commerce storefront built from a Figma design, focusing on clean UI, responsive layouts, and a seamless shopping experience.

🌐 **Live Demo:** [Nexora Shop](https://parsaberah.github.io/nexora-shop/)

## Overview

Nexora Shop is a front-end e-commerce project created to translate a Figma design into a functional, responsive web interface.

The project focuses on the visual implementation of an online store, including product discovery, product presentation, navigation, and shopping-related interactions.

This project is currently a **front-end implementation** and does not include a production backend, payment gateway, or real order-processing system.

## Features

* Modern e-commerce interface
* Responsive layout for desktop and mobile
* Product listing and presentation
* Product categories and navigation
* Shopping cart interface
* Product-focused UI components
* Clean and reusable styling
* Assets organized for easy replacement
* Deployed with GitHub Pages

## Design

The interface was designed in **Figma** and then translated into code.

The implementation focuses on:

* Visual consistency with the original design
* Clear content hierarchy
* Responsive spacing and layouts
* Reusable UI components
* Accessible and intuitive interactions
* A clean and modern shopping experience

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/parsaberah/nexora-shop.git
cd nexora-shop
```

### 2. Install dependencies

If the project uses a package manager:

```bash
npm install
```

### 3. Run the project locally

```bash
npm run dev
```

If the project is built with Vite, the development server will usually be available at:

```text
http://localhost:5173
```

### 4. Build for production

```bash
npm run build
```
